# Prompt 3 — Design exploration, round 2 (three variants)

Run after picking a winner from `prompt-2-design-round-1.md`. Replace `<X>` below with the
chosen direction.

---

Take design direction **`<X>`** from round 1. Produce **three variants** of it.

Everything from round 1 still applies: same audience, same real PID-lesson content, same lesson
index, same hard bans (no gradient hero, no icon-card grid, no emoji headings, no glassmorphism,
no uniform `rounded-2xl shadow-xl`, no stock illustration, no "Unlock the power of…" copy), same
accessibility requirements.

The variants differ **only** along these three axes:

1. **Density** — generous / balanced / compact
2. **Navigation** — persistent sidebar / top bar + in-page TOC / prev-next only
3. **Code emphasis** — code inline in the prose flow / code in a distinct visual track / code in a
   side-by-side column

Don't vary the palette, the type family, or the overall personality — those were settled in round
one. This round is about how the page _works_ for a student reading it, not how it feels.

## Deliverable

Three prototypes. For each, state:

- which combination of the three axes it represents
- who it serves best (a student on a laptop at a meeting? on a phone at home? a mentor scanning
  for the code?)
- what breaks down if a lesson gets twice as long

Then say which one you'd ship and why. Be opinionated — a recommendation with reasons is more
useful than three options presented as equals.
